# 华为云官方开发者大赛参赛与权益指南

## 1. 赛事通道与成长中心联动
华为云成长中心设置了高额赛事激励：
- **每周参与开发者赛事（+100 积分）**：在赛事平台完成一次合法作品或材料提交。
- **开发者赛事晋级（+200 积分）**：作品通过初筛进入下一评审赛程。

## 2. 官方重点赛事与激励机制

### ① 2026华为开发者大赛·小红书Skill创新赛 (ID: 1300000350)
- **官方赛事页**：[赛事主页](https://developer.huaweicloud.com/competition/information/1300000350/introduction)
- **参赛要求**：
  1. 基于 CodeArts 智能体平台或 OfficeAce 构建创新 Skill。
  2. 按照官方规范提交设计方案与代码材料。
- **官方专属权益**：
  - 参赛团队在完成实名认证与报名后，可申请用于比赛算力消耗的专属云服务器代金券。

### ② 鸿蒙与智能体协同创新赛 (ID: 1300000363)
- **提交规范**：
  1. 提交包含项目源码、构建说明（`build-profile.json5`）、以及架构文档的压缩包（`.zip`）。
  2. 作品命名规范：`项目名称+团队名+版本号+联系方式.zip`。

## 3. 合规与注意事项
- 所有作品必须遵守赛事原创与开源许可要求，严禁抄袭或提交虚假项目。
- 参赛团队信息需在华为云“我的团队”板块中进行实名与关联确认。

## 2. 积分架构总览

1. **每日签到**：+10 积分（连续签到奖励递增）
2. **每日浏览鸿蒙案例**：+10 积分（停留 >30 秒）
3. **每日 Star 鸿蒙代码仓**：+30 积分（星标不同案例仓）

5. **每日发布文章**：+60 积分（开发者社区发布技术文章）

### 每周任务（稳定周产出：+470 积分）

3. **每周参与开发者赛事**：+100 积分（提交作品）
4. **每周实践一个实验**：+50 积分（KooLabs 沙箱实验）
5. **每周给 Agent 代码仓提 Issue**：+60 积分（提出改进建议）
6. **每周 Star 一个 Agent 代码仓**：+50 积分
7. **每周参加开发者活动**：+10 积分

### 进阶与官方审核任务（大额产出：+260 ~ +460 积分）

3. **云声建议被实现**：+200 积分 / 条
4. **赛事晋级奖励**：+200 积分
